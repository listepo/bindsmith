# ADR-0001: Dart is the implementation language

Status: accepted (2026-09-08)

bindsmith is written in Dart: core, CLI, drivers, emitters. The official generators (ffigen, jnigen, swiftgen, pigeon, winmd) are Dart libraries and are driven in-process; Dart tooling (dart_style, analyzer) formats and checks the output; distribution is `dart pub global activate` / `dart compile exe`; contributors are the Flutter community. The only non-Dart component is the TypeScript sidecar (`tool/ts_sidecar`) because `.d.ts` semantics need the TypeScript Compiler API; it is spawned as a subprocess and speaks JSON. Rejected: Rust, Kotlin, TypeScript, C# — each would call every upstream generator as a subprocess and could not emit or check Dart natively.
